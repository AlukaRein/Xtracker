# Xtracker
Pencatat Pengeluaran Harian

Aplikasi pencatatan pengeluaran harian berbasis Flutter dengan antarmuka modern (Dark/Obsidian Luxury Theme), grafik distribusi pengeluaran, filter kategori, serta riwayat transaksi.

## Fitur Utama
- **Dashboard Interaktif**: Ringkasan total pengeluaran bulanan, grafik pie & bar chart distribusi pengeluaran.
- **Catat Pengeluaran**: Input cepat dengan kategori dan tanggal yang fleksibel.
- **Riwayat Transaksi**: Kelompokkan transaksi berdasarkan tanggal dengan aksi geser (swipe-to-delete).
- **Penyimpanan Lokal**: Menggunakan `shared_preferences` untuk persistensi data secara offline.
